# Cat Feeding Tracker

## Description
This project is a Python app I created to help track feeding records for my cats. Users can select a cat name, food type, date, vitamin option, and meal time, then save the record.

The app also displays saved feeding records in a table and shows a meal type summary chart. This makes it easier to review feeding patterns and keep cat care organized.

## Features
- Add cat feeding records
- Select cat name, food type, date, vitamin, and meal time
- Save and view feeding records
- Filter records by cat
- Display a meal type summary chart

## Language
Python

## Libraries
